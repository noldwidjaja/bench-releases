# Bench

Builds of Bench, a workstation for your Mac. **[Download Bench.dmg](https://github.com/noldwidjaja/bench-releases/releases/latest/download/Bench.dmg)**,
open it, and drag Bench to Applications. Apple silicon, macOS 14 or later.

Bench isn't signed with an Apple Developer ID, so the first time macOS
blocks it: open System Settings → Privacy & Security and click **Open
Anyway**. After that it keeps itself up to date.
